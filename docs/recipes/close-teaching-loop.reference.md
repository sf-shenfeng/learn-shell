## 一次构思、四处落笔 —— 设计缘由

防的是机械重复——四份文字若是同一句话换四种时态,说明构思那步没做,是在拿四个工具凑数;真正想透的一节课,场评具体到轮次、总评归纳到整体、反思归因到证据、回执列到落点,四份读起来不像复制粘贴。不靠引擎并表(系统不会替你去重四份文字的相似度),靠的是构思顺序本身——先想透,再分头写,自然就不会撞车。
