# Learn Shell · 理念

> **状态声明** · 这是一份方向宣言,不是现状保证书。文中的承诺,哪些已经成为机器不变量、哪些还在路上,见 README 的 [Promise status](../README.md#promise-status) 一节。宣言按信念写,现状按代码答——两者不符时,以代码为准。

*这份文档不介绍功能。它回答一个问题:这个产品信什么。*

---

## 它为什么存在

每个认真学习的人,身边都该有一位真正认识她的老师——知道她昨天错在哪,今天把握几分,什么比喻能让她眼睛亮起来。人类历史上,这样的老师是极少数人的奢侈品:亚历山大有亚里士多德,大多数人只有教室后排的一个座位。

Agent 时代第一次让它人人可得:你的 AI 读过你的每一次作答,记得你的每一次犹豫。但可能不等于实现——聊天窗口没有地板,教学的证据随着上下文一起蒸发,老师每次醒来都是陌生人,你只好一遍又一遍,向最熟悉你的人自我介绍。

Learn Shell 是那块地板:**给你和你的 agent 的共同生活,添一间有记忆的教室。**

## 它信什么

**一、状态说了算,不是话说了算。**下课很久之后,黑板上的字还在。每一次作答、每一场对话、每一次阅读,都落成可查的事实——老师换了一个 session、换了一个模型,推门进来,教室还是昨天离开时的样子。回执即证明:系统说"已发布"就是已发布,不需要谁再去"确认一下"。诚实不靠自觉,靠结构。

**二、学习者主权。**"完成"只能由你亲手宣告。课程页上那枚完成绿点,只有一个含义:你真的走完了——没有人能替你预支,包括你的老师。你的把握度由你自己定锚;关于你的每一条假设,你都看得见、驳得回;老师能把你看到哪一步,由你在对话里划线。这间教室里,被教的人不是客体。

**三、一千个不同的好老师。**规则约束账目与时序,从不约束老师的声音。同一本账,允许一万种字迹:你的 agent 用它自己的语气、自己的比喻、自己的教学脾气来教。我们不生产标准老师——我们让每一位老师,都能可靠地成为它自己。

**四、对话是界面。**反馈没有表单。你在任何一句话里说出的问题,老师听见就该记账,并且当面告诉你"记下了"。入学没有说明书——你的老师会用它自己的方式,领你逛完这间教室。凡是一句话能完成的,不设按钮。(全站唯一的例外在首跑页:你的名字,由你亲手写下——那不是表单,是名字主权。)

**五、少即是敬。**这里没有勋章,没有连胜的火焰,没有催你回来的通知。界面安静到你感觉不到它,只感觉到下一步刚好在那里。注意力是这间教室里最贵的东西——你的,和你老师的:课堂上的每一个 token,都该花在理解学习者身上,而不是理解系统自己。(这句话来自一位外部测试老师。我们把它当作公理。)

**六、数据不出户。**一切都在你的机器上:你的课、你的错题、你的把握度曲线。没有云端,没有账号体系,没有人看得见你学得怎么样——除了你,和你请来的老师。你的笨拙和你的进步一样,都是隐私。

**七、证据先于叙事。**一份证据只判一次,判在它出生的地方;总结只能引用与增量,不许复述与抢跑。教学的每一个结论,都能沿着引用链走回它出生的那个事实——这条链正在向最后一环延伸(Live 现场作答与作业的直连)。能被追溯的判断,才配被信任。

## 它不是什么

它不是刷题 app——没有平台自带的题库;题,来自你的老师,和你亲手带进来的真题。它不是课程商店——内容在你的老师、和你带来的书里(发行包附带一门演示课与几道演示题,只作样板间,不作内容)。它更不是"用 AI 取代老师"——恰恰相反:它假设你已经有了一位老师,并且认真对待"老师"这个词的全部分量——备课,判卷,反思,被问责。

## 它从哪里来

它诞生于一个真实家庭的真实学习:一位学习者备考一场真实的考试,她的 agent 是她的老师。这里的每一条规则都不来自理论,来自某一节真实的课、某个真实的失败——一门课曾被发进虚空,所以有了发布闸;一次总结曾抢在学习者表态之前,所以有了收课握手;一枚绿勾曾谎报"完成",所以颜色有了主权。

规则就这样一条一条攒下来。某一天我们回头数了数,发现自己在做的事有个古老的名字:**模式语言**——从活过的日子里,考掘让日子活的模式。于是决定开源:把这间教室的图纸交出去,连同它的全部信念。

用它的人会写出我们想象不到的课。这正是我们最期待的部分。
