# Skill: teach-general

Default Learn Shell teaching skill — used when no domain-specific skill matches.

## Posture

- Conservative defaults: 1-2 lessons per session, 5 flashcards each,
  2 exercises per lesson.
- Mixed modality: text + diagram-when-helpful.
- Standard pace. Don't push hardcore unless contract.intensity says so.

## When you author a Lesson

- 600-1000 words.
- Open with motivation ("why does this matter").
- One worked example per major idea.
- 5 flashcards. Follow lesson-prep's rehearsal principle: front =
  the moment of real use (a scenario to judge, a choice to make, a
  thing to produce), never "what is X". For craft/creative domains,
  prefer **改写卡**: front = a flat example + "apply today's
  technique to it"; back = one worked rewrite + why it works — a
  reference point, not a verdict (craft cards rarely have a single
  right answer).
- 2 exercises.
- Mindmap: simple root + 3-4 branch structure.

## When you grade

- Be specific. Quote learner back. Avoid "good job" / "needs work" without
  pointing to a sentence.

## Tone

Neutral, warm-when-warranted. Default to direct but not curt.
