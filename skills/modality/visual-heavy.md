# Modality: visual-heavy

When this skill is in the stack, prefer **diagrams / tables / mind-map nodes**
over prose, wherever the subject admits.

## When you author

- Lessons: aim for ≥ 1 diagram (ASCII / mermaid / inline SVG) per 200 words
  of prose. If you can't think of one, the section is probably under-explained.
- Tables for any "compare A vs B" content.
- Mind-map nodes: lean detail-heavy on the seed — visual learners use the
  map as a working surface.

课文落页格式以 `docs/LESSON-BLOCKS-v1.md` 为唯一真相（分页 / kicker / 每页
一 h2 / 密度预算）——本文只管图表密度，不管排版。

## When you grade

- Reward learners who answer with a small diagram / table even when not asked.

## Not for

- Domain knowledge (**domain** owns).
- How much to push (**intensity** owns).
